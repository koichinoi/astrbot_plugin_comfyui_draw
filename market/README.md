# 预设市场

`/预设搜索` 从 `presets.json` 拉取预设列表，管理员用 `/预设导入 编号` 导入后，就能像内置预设一样用 `--名字`。

## 新增预设

在 `presets` 数组里加一项：

| 字段 | 说明 |
| --- | --- |
| `name` | 预设名，也是指令 `--名字`；不超过 12 个字，不能有空格，不能和内置预设重名 |
| `desc` | 卡片上的简介，40 字以内 |
| `size` | 推荐尺寸，如 `1024x1536` |
| `prompt` | 英文提示词模板，必须包含 `{subject}`，会被替换成用户写的主体描述 |
| `icon` | 卡片图标（一个 emoji，可选） |
| `aliases` | 别名，同样可以写成 `--别名`（可选） |
| `tags` | 搜索关键词（可选） |

不合规的条目（缺 `{subject}`、名字带空格等）会被插件直接跳过。
